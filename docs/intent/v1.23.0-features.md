- **User:** Android Discord `354.12` users patching via Morphe Manager from `x2tora/tora-morphe`.
- **Why now:** Extend the newly stabilized 354.12 R8 port (`v1.22.0`) with high-utility messaging, privacy, media, and security features.
- **Success:**
  - `VENUS_ORIGINAL_APK=work/new/base.apk python scripts/build.py` passes.
  - `python scripts/hbc/port_check.py` passes (all Metro module IDs verified).
  - `python scripts/release_notes.py --check` and `python scripts/build.py --metadata-only` pass.
  - Morphe CLI patches `354.12` APKM cleanly with **0 missing DEX references** and **0 register OOB (`REG OOB`) errors** across all DEX classes.
  - Released as `v1.23.0` (`patches-1.23.0.mpp`) on `x2tora/tora-morphe`.
- **Constraint:**
  - R8 `-no-stdlib` safety: all native extension code uses standard Java/Android APIs (`java.util.*`, `java.io.*`, `android.*`, `org.json.*`) without Kotlin stdlib helpers that emit `TypeIntrinsics` or `kotlin/Unit`.
  - `FileModule` single-guard rule: upload features (`stripExif`, `mediaEditor`, `compressUploads`) share a single `uploadBridge` on `FileModule.removeFile` (`compress.mpe`), and all other native features (`urlUnshortener`, `zipPreview`, `reminders`, `appLock`, `latexRender` WebView modal) route through `Diagnostics.dispatch` on `FileModule.clearFolder` (`diag.mpe`).
- **Out of scope:** External backend servers, duplicate `FileModule` method hooks, `androidx.biometric` runtime dependencies, split per-phase GitHub releases.

### Task 2: Native Upload Pipeline Extensions (`extensions/compress/src/main/kotlin/app/venus/compress/MediaCompressor.kt`)
1. **`stripExif` (`action = "stripExif"` or `"prepare"` with `stripExif: true`)**:
   - For JPEG/PNG/WebP images (skipping animated GIFs and animated WebP by inspecting VP8X animation flag in RIFF header), decode bitmap, apply `upright(bitmap, orientation)`, and re-encode without EXIF metadata even when file size is under `limit`.
2. **`mediaEditor` (`action = "editMedia"`)**:
   - When `askDialog: true`, post to main thread (`Diagnostics.currentActivity()`) an Android native `Dialog` showing media duration, Start (sec) / End (sec) inputs, `"Mute audio"` checkbox, `"Apply & Send"`, and `"Send original"`.
   - Use `MediaExtractor` + `MediaMuxer` (`MPEG_4` / `WEBM` / `OGG`) to copy sample data between `startUs` and `endUs` (`SEEK_TO_CLOSEST_SYNC`), omitting the audio track when `mute == true`, and return the output file path/size in JSON.
- **Verify:** `kotlinc -no-stdlib` compiles `compress-classes.jar` with zero `kotlin/Unit` or `TypeIntrinsics` references.

### Task 3: Native Diagnostics & Utility Bridge (`extensions/diag/src/main/kotlin/app/venus/diag/Diagnostics.kt`)
Extend `Diagnostics.dispatch("venus-diag-v1:<action>", argument, promise)` and `Diagnostics.Lifecycle`:
1. **`urlUnshortener` (`venus-diag-v1:unshorten`)**:
   - Background thread follows up to 5 HTTP `HEAD` (fallback `GET` with `Range: bytes=0-0`) hops with `instanceFollowRedirects = false`, 3000ms connect/read timeout, returning JSON `{initial, finalUrl, hops:[...], status}`.
2. **`zipPreview` (`venus-diag-v1:zipList` & `venus-diag-v1:zipRead`)**:
   - `zipList`: Downloads `.zip` URL (capped at 50 MB) to `cacheDir/venus-zip/preview.zip`, iterates entries (max 500 entries, validates against `..` Zip Slip), returns JSON array of `{name, size, compressedSize, isDir, isText}`.
   - `zipRead`: Reads a specific text entry (capped at 128 KB UTF-8) from the cached `.zip` and returns its content.
3. **`reminders` (`venus-diag-v1:reminderSchedule`, `reminderCancel`, `reminderPoll`)**:
   - Persists reminders in `filesDir/venus-reminders.json`, schedules checks on a background/main handler + `AlarmManager` / `NotificationManager` channel `"venus_reminders"`, and fires Android notifications; tapping or polling delivers due reminders to JS.
4. **`appLock` (`venus-diag-v1:lockConfig`, `venus-diag-v1:biometricAuth`)**:
   - In `Diagnostics.Lifecycle.onActivityResumed`, when `appLock` is enabled and app returns from background after timeout, displays a full-screen lock overlay `Dialog` (`FLAG_SECURE`, non-cancelable) and triggers `KeyguardManager.createConfirmDeviceCredentialIntent` / `BiometricPrompt` (API 28+).
   - `venus-diag-v1:biometricAuth` prompts biometric/credential authentication on demand (used to unlock Secret DMs in Venus settings/DM list).
5. **`latexRender` (`venus-diag-v1:latexModal`)**:
   - Opens a native full-screen/bottom-sheet `Dialog` with an offline `WebView` rendering the LaTeX expression cleanly into math typography (with copy raw LaTeX button).
- **Verify:** `kotlinc -no-stdlib` compiles `diag-classes.jar` cleanly.

### Task 4: Runtime JS Implementation (`patches/src/main/resources/venus/bootstrap.js`)
Integrate all 11 features into `bootstrap.js` (settings defaults, feature metadata, icons, search keywords, settings UI pages, and runtime hooks):
1. **`keywordNotify`**: Hook `MESSAGE_CREATE` in Flux dispatcher; match message content against user-configured keywords / `/regex/i` (ignoring own messages, muted/excluded server or channel IDs); trigger notification toast/push & activity log.
2. **`bookmarks`**: Add `"Bookmark message"` / `"Remove bookmark"` in `LongPressMessageActionSheet` (`9978`); store `{id, channelId, guildId, author, content, timestamp}` in `venus-bookmarks.json`; add search, jump-to-message, and delete UI in `Bookmarks` settings screen.
3. **`privacyBlur`**: In `messageRow` (`MessageRowGenerator`), when `privacyBlur` is active and message ID is not in `privacyBlur.revealed`, mark attachments/embeds as `spoiler: true` (and optionally blank `avatarURL`); reveal on tap / action sheet; add quick toggle.
4. **`batchMediaSave`**: In `LongPressMessageActionSheet` (`9978`), when message has 2+ media attachments/embeds, add `"Save all media (N)"` using module `1441` (`downloadMediaAssetWithContentType`) sequentially with progress/completion toast.
5. **`stripExif` & `mediaEditor`**: In `compressUploads` upload hook (`8311`/`8333`/`10366`), route image uploads through `stripExif` even when below size limit, and route video/audio uploads through `mediaEditor` when enabled.
6. **`urlUnshortener`**: In link press handler (`8815`/`9054`), intercept shortened URLs (`bit.ly`, `t.co`, `tinyurl.com`, `is.gd`, `cutt.ly`, `rb.gy`, `shorturl.at`, etc., or all links when configured), call `venus-diag-v1:unshorten`, and show destination dialog with Open / Copy / Cancel.
7. **`zipPreview`**: In `LongPressMessageActionSheet` (`9978`) for messages with `.zip` attachments, add `"Preview ZIP archive"`, calling `venus-diag-v1:zipList` and `venus-diag-v1:zipRead` to display the file tree and text viewer modal.
8. **`reminders`**: In `LongPressMessageActionSheet` (`9978`), add `"Remind me"` (15m / 1h / 3h / Custom); schedule via `venus-diag-v1:reminderSchedule` + JS timer; show due reminder banner/toast with jump-to-message and list in `Reminders` settings screen.
9. **`appLock` & `secretDms`**: Sync lock state via `venus-diag-v1:lockConfig`; filter locked Secret DM channel IDs from private channel lists & notifications until unlocked via `venus-diag-v1:biometricAuth`; add `"Hide as Secret DM"` in channel/message sheet and management UI in `App lock & secret DMs` settings screen.
10. **`latexRender`**: In `messageRowResult`, transform inline `$...$` and block `$$...$$` in `StructurableText` nodes into formatted Unicode math symbols/superscripts/fractions; in `LongPressMessageActionSheet` (`9978`), when a message contains LaTeX math, add `"View math formula"` to open `venus-diag-v1:latexModal`.
